# Security

Please report a vulnerability privately through [GitHub's reporting form](https://github.com/sendscore/sendscore/security/advisories/new), not in a public issue. It covers this repository and [sendscore-app](https://github.com/sendscore/sendscore-app).

Include what you found, how to reproduce it, and which version you used. SendScore is a small project, so a reply may take a few days, and fixes go into the latest release only.

Reports are most useful when they cover parsing hostile mail, fetching links, escaping in reports, or access between accounts in the app.
